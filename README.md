# Databases (SQL): Home Assignment 1 Solution

This repository contains the solution for the first home assignment in the Databases course (Shenkar College, IE&M).

The assignment focuses on fundamental Data Manipulation Language (DML) operations, basic filtering, and querying across multiple related tables.

## Key Skills Demonstrated

* **DML Mastery:** Practical application of fundamental SQL commands: SELECT, WHERE, ORDER BY.
* **Multi-Table Querying (JOINs):** Implementing JOINs to retrieve and combine data from two or more tables (Employees, Jobs, Departments).
* **Filtering and Logic:** Constructing complex WHERE clauses using logical operators (AND/OR) and pattern matching (LIKE).
* **Data Transformation:** Using arithmetic operations within the SELECT clause (e.g., calculating salary increases).
